# RingLink
**RingLink – Browser-Based Voice & Video Calling**

RingLink is a lightweight, browser-based real-time communication platform that allows users to connect with friends, colleagues, or teams through voice and video calls without requiring a SIM card or installing any additional application.

Built using HTML, CSS, JavaScript, PHP, and WebRTC, RingLink provides private room-based communication with a simple, responsive interface. Users can create or join rooms using unique room codes and communicate directly through their web browsers.

### ✨ Key Features

- **Voice Calling:** Make real-time audio calls directly from your browser.
- **Video Calling:** Enjoy browser-based video communication.
- **Room-Based Connections:** Join private rooms using unique room codes.
- **Invite Links:** Generate and share room invitation links.
- **Group Calling:** Support for up to 4 participants per room.
- **Live Chat:** Exchange text messages during calls.
- **Screen Sharing:** Share your desktop screen during meetings.
- **Microphone Controls:** Mute and unmute your microphone.
- **Camera Controls:** Enable, disable, and switch cameras.
- **Speaker Controls:** Adjust audio output and switch supported audio devices.
- **Incoming Call Notifications:** Accept or decline incoming calls.
- **Recent Rooms:** Quickly access previously joined rooms.
- **Progressive Web App (PWA):** Installable experience on supported devices.
- **Offline App Shell:** Service worker caching for basic application availability.

### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- WebRTC
- RTCPeerConnection
- Web Audio API
- MediaDevices API
- Service Workers
- Progressive Web App (PWA)

### 🚀 Project Goal

The goal of RingLink is to make real-time communication simple and accessible by allowing users to connect directly through a web browser without depending on traditional SIM-based calling services.
